# Nuestra Historia ❤️

Un sitio web romántico e interactivo para recordar momentos especiales, celebrar el tiempo compartido y mirar hacia el futuro con esperanza.

## ✨ Características
- Contador de tiempo interactivo con fecha de inicio y pausa/reanudación.
- Carta emotiva con efecto de apertura y sello de lacre.
- Galería de memorias fotográficas con visor lightbox.
- Reproductor de música ambiental romántica.
- Animaciones de partículas, velas y detalles visuales con Tailwind CSS.
- Totalmente configurable desde `config.js`.

## 🚀 Despliegue
Este proyecto está optimizado para funcionar directamente en **GitHub Pages**.
